功能特性

知识管理的一切所需

从简单笔记到 AI 驱动的知识发现

Markdown 卡片

支持 Markdown 富文本编辑、情绪标签、AI 关键词提取，以及智能卡片关联。

RAG AI 对话

基于你的知识库进行 AI 对话，回答附带来源引用。一键将 AI 洞见沉淀为新卡片。

知识拓扑

自动话题聚类，构建层级知识树。AI 将相关卡片综合整理为结构化笔记。

关联网络图

D3.js 力导向图展示卡片关联关系，时间轴回放揭示知识积累过程。

多模型切换

支持 DeepSeek、OpenAI、Claude、Gemini、Moonshot 实时切换，统一 Provider 架构。

团队协作

基于工作区的协作模式，四级权限管理。活动日志和通知系统保持团队同步。

对话分支（Fork）

将任意 AI 对话 Fork 为拓扑子节点，在子话题下深入探索。4 种分支模式：深入探讨、发散探索、总结提炼、质疑挑战。

工作区记忆

AI 在对话过程中自主维护持久化 slug 键值记忆条目，注入 RAG 上下文，提供个性化的连续性回答。

核心亮点

为什么选择 MindCard

RAG 检索增强

AI 回答基于你的知识库，而非通用训练数据

  • BGE-M3 向量搜索 + 全文搜索 + RRF 融合
  • 四级检索深度：纯对话 / 卡片级 / 图增强 / 完整拓扑
  • 引用溯源：点击引用直接跳转源卡片
  • 可选 Web 搜索增强

知识拓扑树

自动构建层级知识结构，AI 辅助梳理

  • 基于 pgvector 的增量语义聚类
  • 自适应阈值，基于工作区相似度分布
  • 4 种 AI 整理模式：自由组织 / 时间线 / 论点论据 / 对比分类
  • 对话可 Fork 为拓扑子节点，4 种分支模式

多模型架构

统一 Provider 注册表，零改动切换模型

  • 6 种 AI 提供商，对话面板实时切换
  • 动态模型列表，自动从 API 拉取
  • raw httpx 直连，无 SDK 依赖
  • 指数退避重试，自动处理 429/5xx

工作区记忆

AI 自主维护持久化记忆，实现个性化连续对话

  • slug 键值 Markdown 记忆条目，对话中实时增删改
  • 记忆注入 RAG 上下文，提供连续性个性化回答
  • 支持通过记忆面板手动查看和编辑
  • 跨对话持久保存，工作区范围内共享
