# MindCard 微信小程序

MindCard 微信小程序是 MindCard 知识卡片平台的移动端子集，专注于**快速记录与随时查阅**。通过小程序，你可以在碎片化时间记录灵感、浏览卡片、与 AI 对话，所有数据与 Web 端实时同步。

## 功能概览

| 功能 | 说明 |
|------|------|
| 快速记录 | 闪念输入，一键保存为卡片 |
| 卡片管理 | 查看、编辑、关联卡片，支持情绪标签与关键词 |
| AI 对话 | 基于知识库的流式 AI 问答（SSE 流式输出） |
| 混合搜索 | 语义搜索 / 全文搜索 / 混合搜索三种模式 |
| 工作区切换 | 支持多工作区，可新建或加入（邀请码） |
| 个人中心 | 账户信息、设置、退出登录 |

## 页面结构

```
pages/
├── index/         首页 — 工作区卡片列表 + 闪念快捷输入 + AI/搜索入口
├── workspace/     工作区管理 — 新建、编辑、加入工作区
├── card-detail/   卡片详情 — 内容、关键词、关联卡片、评论
├── card-edit/     新建/编辑卡片 — Markdown 输入 + AI 润色/补充/关键词/标题
├── ai-chat/       AI 对话 — 流式回复、历史记录、另存为卡片
├── search/        搜索 — 混合 / 语义 / 全文三种模式实时切换
└── profile/       个人中心 — 账户信息、AI 设置、退出登录
```

## 自定义组件

```
components/
├── navigation-bar/   自定义导航栏（支持标题、返回、右侧插槽）
├── card-item/        卡片列表项（标题、关键词、情绪、收藏标记）
├── card-picker/      卡片选择器弹窗（用于 AI 对话上下文切换）
├── icon/             SVG 图标组件（基于 Skyline 兼容的 data URI 方案）
└── markdown-render/  轻量 Markdown 渲染组件（Skyline 兼容）
```

## AI 对话特性

- **流式输出**：SSE 流式接收，300ms 节流刷新，避免高频 `setData` 阻塞渲染
- **稳定渲染**：流式过程显示纯文本（无 Markdown 解析），完成后一次性渲染富文本
- **停止流式**：可随时中断 AI 回复
- **上下文切换**：可在对话中切换关联卡片上下文
- **另存为卡片**：长按 AI 回复，一键存为新卡片
- **历史记录**：查看并切换历史对话

## 搜索功能

- **混合搜索**（默认）：向量语义 + 全文检索 RRF 融合
- **语义搜索**：BGE-M3 向量相似度
- **全文搜索**：PostgreSQL 全文检索
- 输入防抖 400ms，失败自动降级本地搜索

## 工作区协作

- 新建工作区：自定义名称、图标（17 种）、配色（10 种）
- 加入工作区：输入 6 位邀请码
- 生成邀请码：分享给他人加入

## 技术说明

| 项目 | 说明 |
|------|------|
| 渲染引擎 | Skyline（高性能渲染器） |
| API 通信 | `wx.request` + SSE chunked（`enableChunked: true`） |
| 状态管理 | `globalData` + 服务层（card/chat/workspace/notification service） |
| 图标方案 | SVG → data URI（规避 Skyline `<path>` 渲染限制） |
| 认证 | JWT Token，存于 `wx.setStorageSync` |
| 分页 | 游标分页（keyset pagination），`limit ≤ 100` |

## 快速开始

### 环境要求

- 微信开发者工具（最新稳定版）
- 已启动的 MindCard 后端服务（默认 `http://localhost:8000`）

### 配置后端地址

编辑 `miniapp/config.js`：

```js
// 开发环境
const apiBaseUrl = 'http://localhost:8000';

// 生产环境
// const apiBaseUrl = 'https://your-domain.com';
```

> 注意：微信小程序正式版需要在「微信公众平台」后台将后端域名添加到合法域名白名单。

### 导入项目

1. 打开微信开发者工具
2. 选择「导入项目」
3. 目录选择 `miniapp/`（非 workspace 根目录）
4. 填写你的 AppID（或使用测试号）
5. 选择 Skyline 渲染模式

### 登录

小程序支持两种登录方式：

- **账号密码登录**：与 Web 端账号共用
- **开发者快速登录**（`/api/auth/dev-login`）：仅开发环境可用

## 与 Web 端的关系

小程序是 Web 端功能的子集，两端共用同一套后端 API：

| 功能 | Web | 小程序 |
|------|-----|--------|
| 卡片 CRUD | ✅ 完整 Markdown 编辑器 | ✅ 简化编辑 + AI 工具 |
| AI 对话 | ✅ 含 Fork / Memory | ✅ 基础流式对话 |
| 知识图谱 | ✅ D3.js 可视化 | — |
| 拓扑树 | ✅ 树形导航 | — |
| 搜索 | ✅ 全功能 | ✅ 三种模式 |
| 工作区协作 | ✅ 完整权限管理 | ✅ 基础创建/加入 |
| 话题梳理 | ✅ 含模板 | — |
