# MindCard 分层检索 + 图谱增强对话 设计文档

> 日期: 2026-06-02
> 状态: 已批准

## 1. 背景与问题

MindCard 当前存在以下架构混乱：

- **Sage 知识图谱未激活**：实体抽取和图谱存储已在运行，但 GNN 从未训练，GraphRetriever 始终走 embedding fallback（降级为纯向量搜索）
- **RAG/Chat 双模式割裂**：用户需要手动切换"知识问答"和"自由对话"，且 RAG 模式只做卡片检索，不利用图谱
- **分叉管理负担**：手动分叉有时约束思维，用户期望对话自然流动，系统自动组织上下文
- **入口功能混乱**：AI 对话、知识图谱、关联网络、洞察、/rag 页面之间缺乏连接

## 2. 设计目标

1. **分层检索**：统一检索调度器，支持 4 级检索深度（自由→卡片→图谱→全量）
2. **图谱增强对话**：AI 回答时主动引用知识库中的实体和关系
3. **拓扑树隐式维护**：对话自然流动，系统自动维护树结构，用户无感
4. **入口独立、数据联动**：各页面各司其职，通过数据流连接

## 3. RetrievalDispatcher 核心架构

### 3.1 检索级别

```python
class RetrievalLevel(Enum):
    FREE = 0       # 自由对话，无检索
    CARD = 1       # 卡片检索（向量+全文 RRF）
    GRAPH = 2      # 图谱增强（实体+关系+卡片）
    FULL = 3       # 全量感知（+拓扑路径+话题+跨分支）
```

### 3.2 检索结果

```python
@dataclass
class RetrievalResult:
    cards: list[Card]                    # 检索到的卡片
    entities: list[dict]                 # 匹配的实体
    relations: list[dict]                # 实体间关系
    topology_path: list[dict] | None     # 拓扑树路径上下文
    topic_context: dict | None           # 当前话题聚类信息
    reasoning_paths: list[list[str]]     # 图谱推理路径
    level_used: RetrievalLevel           # 实际使用的检索级别
```

### 3.3 调度器接口

```python
class RetrievalDispatcher:
    async def dispatch(
        self,
        question: str,
        level: RetrievalLevel,
        workspace_ids: list[str],
        chat_id: str | None = None,
        db: AsyncSession = None,
    ) -> RetrievalResult
```

### 3.4 Level 自动判断

- `level=auto` 时，系统根据问题特征判断：
  - 短问题（<10字）+ 无专有名词 → Level 1
  - 包含知识库中已知实体 → Level 2
  - 包含"总结""梳理""关联""对比"等关键词 → Level 3
  - 前端也可根据用户选择直接指定

## 4. 各检索级别实现

### Level 0 — 自由对话（FREE）

当前 chat 模式，不变。无检索，纯 LLM + 对话历史。

### Level 1 — 卡片检索（CARD）

当前 rag 模式，不变。调用 `SearchService.hybrid_search()`，返回 top-k 卡片作为上下文。

### Level 2 — 图谱增强（GRAPH）

新增逻辑：

```
问题 → Level 1 的卡片检索结果
     → 实体抽取（复用 triple_extractor）
     → 图谱实体匹配（精确名 + 向量相似度 >0.7）
     → 1-2 跳关系遍历
     → 构建实体上下文块：
       "知识库中的相关概念：
        - [实体A] 是 [实体B] 的 [关系]，关联卡片：[卡片标题]
        - [实体C] 与 [实体D] 存在 [关系]"
     → 卡片上下文 + 实体上下文 → 拼接到 system prompt
```

实体上下文不替换卡片，而是叠加。用户仍看到引用的卡片，AI 多一层"概念关系"理解。

### Level 3 — 全量感知（FULL）

在 Level 2 基础上，额外注入：

1. **拓扑路径上下文**：从 chat_id 找到 tree_node → 沿 parent_id 回溯到 root → 收集路径上每个节点的 title + summary → 注入"你当前的探索路径"
2. **当前节点的关联卡片**：NodeCard 查询当前节点绑定的所有卡片 → 注入"你在这条路径上积累的知识"
3. **跨分支引用**：查询当前节点的 NodeRef → 注入"相关分支：分支C（关系：extends）"

## 5. 拓扑树隐式维护

### 对话开始时

```
系统自动在拓扑树中查找或创建匹配的节点
→ 用对话的前几个问题做 embedding
→ 与现有节点做相似度匹配
→ 匹配度 > 0.7 → 绑定到该节点（复用已有探索路径）
→ 匹配度 < 0.7 → 创建新节点（新的探索方向）
```

### 对话过程中

每次 AI 回答后，系统静默更新节点的 summary（异步后台任务，不影响用户体验）。

### 对话结束时

用户手动沉淀卡片 → 卡片自动归入当前节点（已有逻辑，不变）。

## 6. 分叉改造

### 自然分叉

用户在对话中直接问一个新方向的问题 → 系统检测到话题偏移（embedding 余弦相似度 < 0.5）→ 自动在拓扑树中创建子节点 → 对话中插入轻量分割标记（虚线，非侵入式）→ 用户无感，事后在拓扑图中可看到分叉。

### 手动分叉（保留）

用户点击某条 AI 回复旁的"分叉"按钮 → 同自然分叉，但由用户显式触发 → 分割线更明显（绿色分割条）。

关键区别：不再需要"进入分叉模式"这个步骤。分叉是对话的自然结果。

### 分割线简化

- 进行中：绿色虚线，可折叠
- 已完成：灰色实线，可折叠

取消 "closed" 状态（红色+不可逆），用"已完成"代替。

## 7. Sage 图谱阶段性激活

### 阶段 1（当前可做）：图谱增强检索（Level 2）

不依赖 GNN 训练。只用已有的实体和关系数据：
- 实体匹配：精确名 + embedding 相似度
- 关系遍历：直接查 graph_relations 表
- 卡片关联：通过 entity_cards 表

### 阶段 2（数据积累后）：触发 GNN 训练

当满足以下条件时自动触发：
- 实体数量 > 100
- 距离上次训练 > 7 天
- 新增卡片 > 50 张

### 阶段 3（GNN 就绪后）：激活 GNN 增强

GNN 训练完成后，GraphRetriever._gnn_retrieve() 不再降级：
- 用户提问 → 实体抽取 → GNN 评分 → 混合排序（GNN 60% + 图遍历 40%）
- 前端显示"图谱智能检索"标识

### 阶段 4（长期）：跨分支推理

利用 NodeRef 做跨分支知识关联和知识缺口检测。

## 8. 入口职责划分

| 入口 | 职责 | 不做什么 |
|------|------|----------|
| AI 对话面板 | 知识问答、对话探索、分叉 | 不做图谱可视化 |
| 知识图谱页面 | 浏览实体关系、管理三元组、触发训练 | 不做对话 |
| 关联网络页面 | 卡片之间的相似关系可视化 | 不做实体/三元组 |
| 洞察页面 | 工作区整体知识分析（图谱驱动） | ~~简单全文摘要~~ |
| 卡片编辑器 AI | 润色/补充/标题/关键词 | 不做对话 |

### 数据流

**AI 对话面板**：
- 提问 → RetrievalDispatcher → 检索实体/卡片/拓扑
- 回答中引用实体 → 用户可点击实体名 → 跳转到知识图谱页面
- 沉淀卡片 → 卡片自动关联到当前拓扑节点 + 触发实体抽取

**知识图谱页面**：
- 查看实体 → 可以看到关联的卡片列表
- 点击卡片 → 跳转到卡片详情
- 点击"基于此实体对话" → 打开 AI 对话面板，预填问题

**洞察页面（改造）**：
- 基于图谱的结构化分析，而非全文 dump
- 用户可指定分析范围（某个拓扑分支、某个实体领域、某个话题）
- 输出包含：核心概念、概念间关系、知识缺口、建议探索方向

## 9. 前端改动

### AiChatPanel 输入栏

当前有两个 toggle（RAG/Chat、全局空间）。改为：

```
[深度选择器: 自动 | 卡片 | 图谱 | 全量]  [全局空间 toggle]  [网页搜索 toggle]
```

- 自动（默认）：系统根据问题自动判断 Level
- 卡片/图谱/全量：用户手动指定

### AI 回答中的实体引用

AI 回答时，实体名称用可点击的标签样式渲染，点击后跳转到知识图谱页面。

### 分割线简化

移除 "closed" 红色状态，只保留 active（绿色虚线）和 completed（灰色实线）。

## 10. 实现优先级

| 优先级 | 内容 | 依赖 |
|--------|------|------|
| P0 | RetrievalDispatcher + Level 0/1 | 无 |
| P1 | Level 2（图谱增强）| 无（已有实体数据） |
| P1 | 前端深度选择器 | RetrievalDispatcher |
| P2 | 拓扑树隐式维护 | 无 |
| P2 | 分叉简化 + 自然分叉 | 无 |
| P2 | 洞察页面改造 | Level 2 |
| P3 | Level 3（全量感知）| 拓扑树维护 |
| P3 | 实体引用可点击 | Level 2 |
| P4 | GNN 训练触发 | 数据积累 |
| P4 | GNN 增强检索 | GNN 训练完成 |
